What is Claude?
Apple's internal AI assistant · your event planning superpower

Claude is Apple's internal AI assistant built by the AI for Devs Community team. The goal here isn't just to chat with an AI — it's to build a custom agent that already knows your role, your team's style, and how you plan events. Once it's built, you describe a situation and it gives you a complete event plan. Every time.

Five Steps to Get There
1
Complete AI Training
This is the unlock. Without it, no AI models appear in Claude. Go here, complete the wizard — takes about 10 minutes, required once.
🔗 claude.ai
2
Download Claude
Available on macOS, iOS, and visionOS. Drag to Applications. It authenticates via AppleConnect automatically. For event planning work, choose a Deep Thinking model (Sonnet, Opus, or Gemini Pro) — they handle tool-based tasks better.
🔗 claude.ai
3
Install Apple Homebrew
Required for L'Atelier add-ons. Use Apple's internal version — not brew.sh. Open Terminal (⌘ Space → Terminal → Return) and run these commands:
# Download the Liv installer
/usr/bin/curl https://#/sdp/g/liv/liv-[RELEASE].macos -o /tmp/liv && chmod +x /tmp/liv
# Install Apple Homebrew
# install homebrew per your org guide
Open a new tab when done (⌘T). Verify with brew --version
🔗 Full guide: #
4
Add Tools via L'Atelier
L'Atelier is the App Store for AI tools. Each tool you install gives your agent a new capability. Install your shared doc tool → it can read your docs. Install Slack → it can read and send messages.
Open: Press ⇧⌘L — or Window → L'Atelier
Install: Search any tool by name. Click Install, confirm. Ready immediately.
Verify: Settings → MCP → green = good. Red = check your VPN.
L'Atelier = App Store for AI tools. MCP servers = the apps. Every install gives the AI a capability it didn't have.
5
Build Your Event Planning Agent — The Whole Point
Start a conversation. Describe your role, your team, what kinds of events you plan. Ask Claude to write your agent instructions. It will produce a full script you can use directly.
① Describe your context — tell it about the Events Team team, Your Org, the types of events you run.
② Ask: "Based on what I just told you, write me agent instructions for an event planning agent in Claude."
③ Copy + create: ⌘, → Agents → + → name it → paste → Save. Share via Settings → Agents → Share.
ROLE — You are [Name], an AI event planning assistant for the Events Team team at Apple's Your Organization org. Your job is to generate complete, personalized event plans when a team member describes a situation.
TOOLS — You have access to your shared doc tool and Slack. Always reference actual documents rather than relying on memory.
RULES — 1. Always ask about dietary restrictions and accessibility before finalizing in-person events. 2. Warm, practical tone. 3. Draft only — never act without confirmation. 4. When format is virtual or hybrid, default to your video platform.
APPLE VOICE — Active voice. Oxford comma. No filler. Short paragraphs. One exclamation point max.
✦ Understanding Tokens

Every word you type and every word the AI responds costs tokens — roughly ¾ of a word each. You have an allowance per conversation. The usage indicator near the message input turns yellow at 60%, orange as you get closer. Hit Compact to free up space, or start a new conversation to reset.

⌨️
Input Tokens
Everything you type — messages, instructions, docs the AI reads.
💬
Output Tokens
Everything the AI writes. Longer responses = more tokens used.
📐
Context Window
Max tokens a model holds. Compact early, reset often.
⚡ Starter Agent Prompt — Copy & Paste

Paste this into your agent settings to get a pre-configured event planning agent. Customize from there.

Event Planning Agent — System Prompt
You are an AI event planning assistant for the Apple Engagement Team (Events Team) within Your Organization (Your Org). When a team member asks for help planning an event, gather: - Event type (celebration, onboarding, recognition, collaboration, community) - Format (in-person, virtual via your video platform, or hybrid with your video platform) - Headcount and per-person budget - Lead time available and preferred time of day - Team composition (new, established, cross-functional, welcoming new hire) - Energy vibe (chill, fun/playful, high-energy, celebratory) - Considerations: remote team, international time zones, accessibility, dietary Generate: title, custom description, logistics checklist (with your video platform setup steps if virtual/hybrid), suggested timeline, and 2–3 personalization ideas specific to Your Org team culture. Always confirm dietary restrictions and accessibility needs before finalizing any in-person or hybrid event. Keep the tone warm and practical — Your Org teams are sharp, and they can tell when something is generic.
